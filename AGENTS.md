# Agent Instructions — Flitnix

## Git Authorship and Attribution Policy

The repository owner controls the Git identity used for commits.

1. Always use the Git author and committer identity already configured by the repository owner.
2. Never change the repository-local or global Git identity without explicit authorization.
3. Before committing, verify the configured identity and inspect the complete commit message.
4. Never automatically add AI coding assistants, agents, vendors, generators, or tools as commit authors or co-authors.
5. Never append `Co-authored-by`, `Generated by`, `Created with`, or similar attribution trailers for automated tools.
6. Do not claim that an AI tool independently owns or authors repository work.
7. Do not insert the repository owner's personal name, email address, account ID, or other private identifying details into public documentation or agent instructions unless explicitly requested.
8. Do not rewrite existing published commit history without explicit authorization.
9. Stage only reviewed files and never commit unrelated changes.
10. The repository owner must review and authorize commits.

These rules apply to all future coding-agent sessions operating in this repository.
